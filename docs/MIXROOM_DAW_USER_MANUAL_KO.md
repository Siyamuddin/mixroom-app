# Mixroom DAW 사용자 매뉴얼

한국어 버전  
권장 원본 형식: Markdown  
권장 배포 형식: PDF, 검토용 DOCX

## 1. 목적

이 문서는 Mixroom DAW 오디오 에디터에서 사용자가 할 수 있는 주요 기능을 설명합니다. 개발 문서가 아니라 제품 사용 매뉴얼입니다.

다루는 내용:

- 프로젝트와 화면 구조
- 재생, 녹음, 전송 컨트롤
- 타임라인 도구와 클립 편집
- 트랙 Row, 믹서, 이펙트, 오토메이션
- 샘플 브라우저, 가져오기, 내보내기
- MIDI와 피아노 롤
- AI 채팅 기능, 실행 가능한 작업, 제한 사항

- 데스크톱 플러그인 매니저

## 3. 메인 화면 구조

DAW는 타임라인을 중심으로 구성됩니다. 상단에는 프로젝트 컨트롤, 중앙에는 Row와 클립, 하단에는 채팅과 전송 컨트롤이 있습니다.

![Mixroom DAW overview](assets/daw_manual/android_daw_overview.png)

```text
상단 툴바
뒤로 | 프로젝트 설정 | 시간 / 템포 / 키 | 마스터 버스 | 분석기 | 내보내기

타임라인
Row와 M/S 버튼 | 오디오/MIDI 클립 | 재생 헤드 | 오토메이션 레인

하단 컨트롤
추가 메뉴 | AI 채팅 바 | 실행 취소/다시 실행 | 처음으로 | 재생/일시정지 | 녹음 | One-Button Mix
```

기본 작업 흐름:

1. 오디오 또는 MIDI를 추가하거나 녹음합니다.
2. 클립을 Row에 배치합니다.
3. 클립의 위치, 길이, 피치, 게인, 템포 동작을 편집합니다.
4. Row 컨트롤, 이펙트, 오토메이션, 마스터 버스로 믹스합니다.
5. AI 채팅으로 안내, 편집, 믹스 작업을 수행합니다.
6. 결과물을 내보냅니다.

## 4. 상단 툴바

### 뒤로

에디터에서 이전 화면으로 돌아갑니다. 프로젝트 이름이 필요한 경우 Mixroom이 이름 입력을 요청합니다.

### 프로젝트 설정

프로젝트 단위 설정을 엽니다.

![Project settings](assets/daw_manual/android_project_settings.png)

설정 항목:

- 프로젝트 이름
- 입력 장치
- 입력 채널
- 출력 장치 또는 출력 경로
- 필요 시 Bluetooth 녹음 정책
- 크로스페이드 모드
- 메트로놈 켜기/끄기
- 메트로놈 볼륨
- 지원되는 경우 프로듀서 캡처 UI
- 지원되는 데스크톱 빌드의 MIDI 키보드 입력
- 데스크톱 스페이스바 동작
- 키보드 단축키
- 데스크톱 플러그인 매니저
- 진단 정보
- 프로젝트 복구 알림
- DAW 튜토리얼 다시 보기

### 시간 / 템포 / 키

중앙 툴바는 현재 시간, 프로젝트 길이, BPM을 보여줍니다. 탭하면 템포 컨트롤이 열립니다.

![Tempo, key, and project tempo mode](assets/daw_manual/android_tempo_stretch_panel.png)

템포 컨트롤:

- 20-999 BPM 선택
- BPM 직접 입력
- 프로젝트 키 선택
- 템포 모드: Off, Resample, Stretch

템포 모드는 오디오 클립이 BPM 변경을 따라가는 방식을 결정합니다.

| 모드 | 동작 |
| --- | --- |
| Off | 클립이 프로젝트 템포 변경을 따르지 않습니다. |
| Resample | 클립이 템포를 따라가지만 재생 속도와 피치가 함께 바뀔 수 있습니다. |
| Stretch | 클립이 템포를 따라가며 피치를 유지합니다. |

프로젝트 템포 모드는 프로젝트 전체 기본 동작을 정합니다. 기존 오디오 클립은 클립별 템포 모드를 따로 가질 수 있습니다. 클립이 Off로 되어 있으면 프로젝트를 Stretch로 바꿔도 해당 클립은 템포를 따라가지 않습니다. 그 클립도 Clip Settings에서 Resample 또는 Stretch로 설정해야 합니다.

### 마스터 버스

마스터 버스 패널을 엽니다. 프로젝트 전체 출력에 적용되는 처리 단계입니다.

![Master bus panel](assets/daw_manual/android_master_bus.png)

마스터 버스 항목:

- 마스터 볼륨
- 마스터 팬
- 마스터 레벨 미터
- Row별 게인 스테이징 표시
- 마스터 이펙트 체인
- 전체 FX 바이패스

### 데스크톱 분석기

데스크톱에서는 상단 툴바에 마스터 출력의 간단한 분석기/시각화가 표시될 수 있습니다.

### 내보내기

프로젝트를 렌더링하고 저장하거나 공유할 수 있는 내보내기 흐름을 엽니다.

## 5. 전송 컨트롤

전송 컨트롤은 에디터 하단에 있습니다. 데스크톱에서는 채팅 바 옆에 배치됩니다.

| 컨트롤 | 기능 |
| --- | --- |
| Undo | 마지막 지원 작업을 되돌립니다. |
| Redo | 되돌린 작업을 다시 적용합니다. |
| Restart | 재생 위치를 처음으로 이동합니다. 루프가 켜져 있으면 루프 시작점으로 이동합니다. |
| Play/Pause | 재생 또는 일시정지합니다. |
| Record/Stop | 선택된 Row에 녹음을 시작하거나 현재 녹음을 중지합니다. |
| One-Button Mix | 자동 Mixroom 믹스 패스를 실행합니다. |

녹음에는 선택된 Row와 사용 가능한 입력 장치가 필요합니다. 권한이나 입력 장치가 없으면 안내 메시지가 표시됩니다.

### One-Button Mix

One-Button Mix는 현재 프로젝트에 대해 자동 믹스 패스를 실행합니다. 최종 마스터링 결정보다는 시작점으로 사용하는 기능입니다.

조정할 수 있는 항목:

- Row 밸런스
- 게인
- 팬
- EQ
- 다이내믹스
- 이펙트
- 마스터 처리

실행 후에는 반드시 프로젝트를 재생해 보며 보컬 레벨, 저역 밸런스, 거친 고역, 마스터 라우드니스를 확인한 뒤 내보내는 것이 좋습니다.

## 6. 추가 메뉴

추가 버튼은 세 가지 주요 옵션을 엽니다.

![Add menu](assets/daw_manual/android_add_menu.png)

| 버튼 | 기능 |
| --- | --- |

| Add Instrument Clip | 악기 선택기를 통해 MIDI/악기 클립을 만듭니다. |

## 7. 타임라인 도구

타임라인에는 다섯 가지 주요 도구가 있습니다.

| 도구 | 용도 |
| --- | --- |
| Select | 기본 편집 도구입니다. 클립 선택, 이동, 트림, 클립 컨트롤 열기, 다중 선택에 사용합니다. |
| Stretch | 오디오 클립 가장자리를 드래그해 길이를 수동으로 늘리거나 줄입니다. |
| Paint | 복사된 클립을 타임라인에 반복 배치합니다. 드럼, 루프, 반복 FX, 반복 구간에 유용합니다. |
| Cut | 선택한 타임라인 지점에서 클립을 자릅니다. 자석이 켜져 있으면 선택된 퀀타이즈 그리드에 맞춰 잘립니다. |
| Delete | 클립을 탭하거나 드래그해 삭제합니다. 빠른 정리에 유용합니다. |

휴대폰과 태블릿에서는 Select 도구가 활성화된 상태에서 첫 클립을 길게 눌러 다중 선택을 시작한 다음, 다른 클립을 탭해 선택에 추가합니다. 선택된 클립 중 하나를 드래그하면 그룹 전체가 이동합니다. 빈 타임라인을 탭하면 그룹 선택이 해제됩니다. 빈 타임라인을 길게 누른 뒤 드래그하면 여러 클립을 둘러싸는 선택 상자를 만들 수 있습니다.

타임라인 도구 메뉴의 **Foreground grid**를 켜면 마디, 비트, 퀀타이즈 선이 오디오 및 MIDI 리전 위에 표시되어 파형과 음악 그리드의 정렬을 함께 볼 수 있습니다.

### 자석과 퀀타이즈

자석 버튼은 타임라인 스냅을 제어합니다.

| 동작 | 결과 |
| --- | --- |
| 자석 탭 | 스냅을 켜거나 끕니다. |
| 자석 길게 누르기 | 퀀타이즈 메뉴를 엽니다. |
| 퀀타이즈 값 선택 | 1/4, 1/8, 1/16 같은 스냅 그리드를 정합니다. |

자석이 켜져 있으면 클립, 컷, 붙여넣기, Paint 배치, 루프 구간, 오토메이션 구간이 선택한 음악 그리드에 맞춰집니다.

자석이 꺼져 있으면 자유롭게 배치하고 편집할 수 있습니다. 대사 편집, 사운드 디자인, 느슨한 연주, 세밀한 정리에 적합합니다.

퀀타이즈 값은 한 마디를 나누는 기준입니다.

| 값 | 의미 |
| --- | --- |
| 1/1 | 한 마디 |
| 1/2 | 반 마디 |
| 1/4 | 일반적인 4/4 기준 4분음표 그리드 |
| 1/8 | 8분음표 그리드 |
| 1/16 | 더 촘촘한 16분음표 그리드 |

음악적인 편곡 작업에는 자석을 켜고, 그리드가 너무 넓거나 촘촘하면 자석 버튼을 길게 눌러 퀀타이즈 값을 바꾸세요.

타임라인은 다음 기능도 지원합니다.

- 가로 스크롤
- 기기별 핀치/휠 줌
- 터치 팬 또는 줌 중에는 소리 없이 이동하고 제스처가 끝날 때 한 번만 재생 헤드 이동
- 그리드 표시
- 클립 선택과 다중 선택
- 루프 구간 표시
- 파형과 MIDI 미리보기
- 오토메이션 클립 표시
- 크로스페이드 시각화
- 녹음 오버레이

## 8. Row와 트랙 컨트롤

Row는 DAW의 트랙 레인입니다. 각 Row에는 오디오 클립, MIDI 클립, 오토메이션, Row 이펙트를 둘 수 있습니다.

### Row 헤더

Row 헤더에는 다음 항목이 있습니다.

- Row 아이콘
- Row 선택
- 펼치기/접기
- M 음소거
- S 솔로
- 오토메이션이 보일 때 레인 접기/펼치기 표시

### Row 메뉴

Row 메뉴:

- 위에 Row 삽입
- 아래에 Row 삽입
- Row 위로 이동
- Row 아래로 이동
- Row 이름 변경
- Row 아이콘 선택
- Row 삭제

### Add Row

빈 Row를 추가합니다. 최대 Row 수에 도달하면 제한 안내가 표시됩니다.

## 9. Row 볼륨

Row를 펼치면 Volume 탭에서 Row 단위 믹싱 컨트롤을 사용할 수 있습니다.

![Expanded row volume controls](assets/daw_manual/android_row_expanded.png)

주요 컨트롤:

- 게인
- 팬
- 스테레오 미터
- dBFS 피크/표시
- 게인/팬 초기화 동작

기본 밸런스는 이펙트를 추가하기 전에 Row 볼륨으로 맞추는 것이 좋습니다. 마스터 볼륨은 전체 최종 레벨 조정에 사용합니다.

## 10. 클립 편집

클립을 선택하면 간단한 작업 팝오버가 열립니다.

![Selected clip popover](assets/daw_manual/android_clip_popover.png)

| 클립 팝오버 버튼 | 기능 |
| --- | --- |
| Copy | 선택한 클립 또는 클립 그룹을 복사합니다. |
| Place clone | 복사한 클립을 선택 지점 근처에 붙여넣거나 클론으로 배치합니다. |
| Clip settings | 자세한 클립 설정을 엽니다. |
| Split at playhead | 가능한 경우 재생 헤드 위치에서 오디오 클립을 자릅니다. |
| Delete | 선택한 클립 또는 클립 그룹을 삭제합니다. |

### 클립 설정

클립 설정 항목:

- 클립 이름 변경
- 클립 게인
- Normalize
- 피치 시프트
- 템포 모드: Off, Resample, Stretch
- 오디오 뒤집기
- 템포 감지
- 지원되는 경우 보컬 분리

### 템포 스트레칭과 클립 스트레칭

Mixroom에는 서로 관련 있지만 다른 두 가지 스트레치 흐름이 있습니다.

| 흐름 | 위치 | 사용할 때 |
| --- | --- | --- |
| Tempo Mode Stretch | 프로젝트 템포 패널과 Clip Settings | 루프나 오디오 클립이 프로젝트 BPM을 따라가면서 피치는 유지해야 할 때 |
| Stretch 도구 | 타임라인 도구 메뉴 | 클립 가장자리를 드래그해 길이를 직접 바꾸고 싶을 때 |

템포를 따라가는 오디오를 만들려면 프로젝트 설정과 클립 설정을 함께 확인하세요.

1. 상단 툴바에서 템포 패널을 엽니다.
2. 피치를 유지하면서 BPM 변경을 따라가려면 Tempo Mode를 Stretch로 설정합니다.
3. 오디오 클립을 선택합니다.
4. Clip Settings를 엽니다.
5. 클립 템포 모드를 Stretch로 설정합니다.
6. 프로젝트 BPM을 변경합니다. Stretch로 설정된 클립은 피치를 유지하면서 프로젝트 템포를 따라갑니다. Off 클립은 독립적으로 유지됩니다.

프로젝트 Stretch는 프로젝트의 템포 팔로우 동작을 켭니다. 하지만 기존 오디오 클립은 각 클립에서도 템포 팔로우가 켜져 있어야 합니다. 새로 가져온 클립이나 AI가 만든 템포 인식 클립은 이미 설정되어 있을 수 있지만, 기존 클립은 Clip Settings에서 확인하는 것이 좋습니다.

타임라인 Stretch 도구는 별도입니다. 이 도구는 선택된 오디오 클립의 길이를 직접 바꿉니다. 가장자리 스트레칭 중에는 해당 클립의 템포 팔로우가 켜지고 스트레치 엔진으로 새 길이에 맞춰집니다.

### 트림, 이동, 스트레치, 분할

가능한 작업:

- 클립을 다른 시간으로 드래그
- 클립을 다른 Row로 드래그
- 클립 시작/끝 트림
- 오디오 클립 길이 스트레치
- 재생 헤드에서 오디오 분할
- 클립 복사와 복제
- 클립 삭제

다중 선택을 사용하면 여러 클립을 함께 이동, 복사, 삭제할 수 있습니다. 휴대폰과 태블릿에서는 첫 클립을 길게 누르고 나머지 클립을 탭한 다음, 선택된 클립 중 하나를 드래그하거나 그룹 팝오버 작업을 사용합니다.

### 루프 구간

루프는 선택한 타임라인 구간을 반복 재생합니다. 파트 작성, 편집 확인, 특정 구간 믹스, 오토메이션 연습에 유용합니다.

모바일:

- 타임라인 룰러를 탭해 루프 구간 생성
- 룰러를 드래그해 원하는 길이의 루프 생성
- 루프 핸들을 드래그해 시작/끝 조정
- 루프 안쪽을 드래그해 구간 이동
- 현재 루프 밖을 탭해 루프 해제

데스크톱:

- 룰러 좌클릭/드래그로 재생 헤드 이동
- 룰러 우클릭으로 루프 생성 또는 해제
- 룰러 우클릭 드래그로 루프 생성, 크기 조절, 이동

루프가 켜져 있으면 Restart는 루프 시작점으로 이동합니다. 재생 중에는 루프 끝에서 루프 시작으로 돌아갑니다.

### 크로스페이드

프로젝트 설정에는 크로스페이드 동작이 있습니다.

- Off
- Cut
- Linear Crossfade
- Equal Power Crossfade
- S-Curve Crossfade

크로스페이드는 클립 경계가 만나거나 겹칠 때 클릭을 줄이고 전환을 부드럽게 합니다.

사용 가능 여부는 플랫폼과 플러그인 포맷 지원에 따라 다릅니다.

외부 플러그인 호스팅은 Mixroom 내장 이펙트와 별도입니다. 내장 이펙트는 Mixroom 이펙트 이름으로 호출됩니다. 외부 플러그인은 설치된 포맷과 플랫폼 지원에 따라 달라집니다.

## 12. 마스터 버스

마스터 버스는 내보내기 전 마지막 처리 단계입니다.

포함 항목:

- 마스터 게인
- 마스터 팬
- 마스터 스테레오 미터
- Row 게인 스테이징 카드
- 마스터 이펙트
- 전체 FX 바이패스

마스터 버스는 전체 라우드니스와 클리핑을 확인하는 곳입니다. 마스터 미터가 너무 뜨거우면 리미터를 더 넣기 전에 Row 게인이나 마스터 게인을 낮추세요.

### 마스터 버스 개념

모든 Row는 결국 마스터 버스로 흐릅니다. 마스터 버스는 프로젝트 전체 출력에 영향을 주므로 여기에서 바꾸는 내용은 청자가 듣는 전체 소리에 적용됩니다.

특정 소리만 조정해야 한다면 먼저 Row 컨트롤을 사용하세요. 전체 프로젝트의 최종 레벨, 톤, 폭, 컴프레션, 리미팅, 내보내기 전 폴리시가 필요할 때 마스터 버스를 사용합니다.

### 게인 스테이징

게인 스테이징은 클립, Row, 이펙트 체인, 마스터 각 단계의 레벨을 건강하게 유지하는 것입니다.

좋은 게인 스테이징은 왜곡을 막고 믹스를 쉽게 만듭니다.

- 클립 게인은 Row 믹싱 전 개별 클립 레벨을 정합니다.
- Row 게인은 트랙 레인 간 밸런스를 맞춥니다.
- 이펙트 입력/출력 레벨은 플러그인이 과하게 밀리지 않게 합니다.
- 마스터 게인은 내보내기 전 최종 프로젝트 레벨을 조정합니다.

마스터 미터가 클립되면 리미터에 의존하기 전에 Row 게인이나 큰 클립 게인을 낮추세요. 리미터는 피크를 잡는 도구이지, 균형이 나쁜 믹스를 숨기는 도구가 아닙니다.

## 13. 오토메이션

오토메이션은 컨트롤 값을 시간에 따라 바꾸는 기능입니다. 볼륨, 팬, 이펙트 파라미터를 고정값으로 두지 않고 타임라인에서 변화하도록 만들 수 있습니다.

사용 예:

- Row 페이드 인/아웃
- 보컬 구간에서 다른 Row 낮추기
- 드롭 전 필터 스윕
- 문장 끝에만 리버브 증가
- 딜레이 throw
- 볼륨 오토메이션으로 리듬 펌핑 만들기

![Automation tab](assets/daw_manual/android_automation.png)

오토메이션 대상:

- Row 볼륨
- Row 팬
- 플러그인 파라미터
- 마스터 게인
- 마스터 팬
- 마스터 이펙트 파라미터

### 오토메이션 작동 방식

오토메이션은 레인 위의 포인트로 만들어집니다.

- 각 포인트에는 시간 위치가 있습니다.
- 각 포인트에는 값이 있습니다.
- 포인트 사이의 선은 값이 어떻게 변하는지 보여줍니다.
- 재생 중 Mixroom은 이 선을 따라 값을 움직입니다.

예를 들어 두 개의 볼륨 포인트로 페이드를 만들 수 있습니다.

1. 페이드 시작 위치에 낮은 값의 포인트를 추가합니다.
2. 뒤쪽에 높은 값의 포인트를 추가합니다.
3. 재생 중 Mixroom이 두 포인트 사이에서 볼륨을 올립니다.

오토메이션은 대상에 속합니다. 대상을 바꾸면 레인이 편집하는 컨트롤도 바뀝니다. 한 Row에는 볼륨, 팬, 지원되는 플러그인 파라미터별 오토메이션 레인이 있을 수 있습니다.

### Automation 탭

펼친 Row의 Automation 탭에서 가능한 작업:

- 오토메이션 대상 선택
- 포인트 추가
- 포인트 드래그
- 모든 포인트 복사
- 포인트 붙여넣기
- 선택한 시간 범위 복사
- 복사한 범위를 재생 헤드에 붙여넣기
- 정확한 값 입력
- 이전 포인트 값과 맞추기
- 포인트 삭제

중요 컨트롤:

| 컨트롤 | 기능 |
| --- | --- |
| Target selector | Volume, Pan, 이펙트 파라미터 등 편집할 대상을 선택합니다. |
| Point lane | 오토메이션 포인트와 값 곡선을 보여줍니다. |
| Copy | 현재 대상의 모든 포인트를 복사합니다. |
| Paste | 복사한 포인트를 현재 대상에 붙여넣습니다. |
| Copy range | 선택한 시간 범위만 복사합니다. 보통 현재 루프 범위에 유용합니다. |
| Paste range | 복사한 범위를 재생 헤드 또는 대상 위치에 붙여넣습니다. |
| Link/chain button | 오토메이션된 파라미터로 이동합니다. 플러그인 오토메이션의 경우 Mixroom이 플러그인/이펙트 패널을 열고 해당 파라미터를 하이라이트해 어떤 컨트롤이 자동화되는지 보여줍니다. |

편곡상의 움직임에는 Row 볼륨 오토메이션을 사용하세요. 사운드 자체가 바뀌어야 할 때는 필터 컷오프, 리버브 믹스, 딜레이 피드백, 드라이브 같은 플러그인 오토메이션을 사용합니다.

### 오토메이션 클립

오토메이션 클립은 타임라인에 보이는 재사용 가능한 오토메이션 구간입니다.

컨트롤:

- 파라미터 열기
- 포인트 편집
- 클론
- Make Unique
- 삭제

클론된 오토메이션 클립은 같은 패턴을 공유합니다. 한 복사본만 다르게 편집해야 하면 Make Unique를 먼저 사용하세요.

오토메이션 클립은 같은 움직임이 반복될 때 유용합니다. 예를 들어 사이드체인 느낌의 펌핑 패턴을 여러 마디에 복제할 수 있습니다.

### 오토메이션 템플릿

AI 어시스턴트는 다음과 같은 일반적인 오토메이션 모양을 만들 수 있습니다.

- sidechain pump
- reverb tail
- filter sweep
- sidechain from kick

## 16. MIDI와 피아노 롤

악기 클립은 피아노 롤에서 열립니다.

Add Instrument Clip으로 MIDI/악기 클립을 만들고, 클립을 열어 피아노 롤에서 노트를 편집합니다.

### 피아노 롤 헤더

피아노 롤 항목:

- MIDI 탭
- Instrument 탭
- 지원되는 경우 외부 악기 UI 열기
- 도구 메뉴
- 재생 헤드 따라가기 잠금
- 줌 아웃
- 줌 인
- 도움말
- 전체화면 토글
- 닫기

### MIDI 편집

가능한 작업:

- 그리드에 노트 추가
- 빈 그리드 셀을 탭해 노트 배치
- 노트 선택
- 박스 선택
- 노트 드래그
- 노트 길이 조절
- 노트 복사
- 노트 붙여넣기
- 노트 복제
- 노트 삭제
- 선택 노트 velocity 조정
- 선택 노트 길이 스케일 조정

모바일에서는 탭으로 노트를 추가하는 방식이 가장 빠릅니다. MIDI 클립을 열고, 원하는 음 높이와 박 위치를 고른 뒤 그리드를 탭하세요. 가로로 드래그하면 타이밍이 바뀌고, 세로로 드래그하면 피치가 바뀌며, 노트 가장자리를 조절하면 길이가 바뀝니다.

### 피아노 롤 도구

도구 메뉴:

- Select All
- Quantize All Notes
- Quantize Selected
- Chop All Notes
- Chop Selected
- Humanize Velocity
- Octave Up
- Octave Down

### Instrument 탭

Instrument 탭에서는 악기 사운드를 선택하고 확인합니다.

지원 항목:

- 카테고리 칩
- 악기 목록
- 악기 배지
- 악기 파라미터 컨트롤
- 지원되는 경우 외부 플러그인 악기 UI 열기

악기 카테고리에는 온디바이스 악기, keys, strings, woodwinds, percussion, pads, leads, bass, plucks, synths, brass, drums 등이 포함될 수 있습니다.

## 17. 녹음

녹음은 전송 컨트롤의 Record 버튼에서 시작합니다.

녹음 전 확인:

- 대상 Row 선택
- 입력 권한 확인
- 입력 장치 선택
- 여러 채널이 있으면 입력 채널 선택
- 필요 시 메트로놈 켜기

녹음 중에는 Record 버튼이 Stop 역할을 합니다. 녹음이 끝나면 사용 가능한 오디오 데이터가 있을 경우 Mixroom이 프로젝트에 클립을 추가합니다.

Bluetooth 마이크와 모니터링은 플랫폼별로 다를 수 있습니다. Bluetooth 출력에서는 고급 오버라이드가 켜져 있지 않으면 실시간 모니터링이 비활성화될 수 있습니다.

### MIDI 녹음

라이브 MIDI 입력을 사용할 수 있는 경우 MIDI 녹음은 선택된 악기/MIDI 대상을 사용합니다.

MIDI 녹음 전:

- 악기 클립을 만들거나 선택
- 악기 사운드 선택
- MIDI 가능한 Row 또는 클립 선택
- MIDI 입력 연결 또는 지원되는 데스크톱 빌드에서 키보드 MIDI 입력 켜기
- Record 누르기

녹음된 MIDI 노트는 대상 클립에 추가되며 이후 피아노 롤에서 편집할 수 있습니다.

## 21. AI 채팅 개요

Mixroom에는 프로젝트를 이해하는 AI 채팅 바가 DAW 하단에 있습니다.

![AI chat panel](assets/daw_manual/android_ai_chat.png)

AI 채팅이 할 수 있는 일:

- DAW 질문에 답변
- 믹싱 개념 설명
- 무엇을 바꿨는지 설명
- 현재 프로젝트 분석
- UI 컨트롤 안내
- 믹스 작업 제안 또는 실행
- 레퍼런스 트랙 기반 믹스 매칭
- 클립 편집
- 이펙트 편집
- 오토메이션 생성
- MIDI 생성 또는 수정
- 샘플 삽입
- 지원되는 경우 스템 분리
- 트랙 역할 라벨 설정 또는 해제

채팅 바 항목:

- 도움말/기능 버튼
- 프롬프트 입력
- 보내기 버튼
- 처리 중 Stop 버튼
- 프롬프트 제한 배지
- 확장된 채팅 기록
- 피드백 버튼
- 채팅 기록 지우기

### 프롬프트 제한

프롬프트 제한 배지는 현재 제한 기간에 사용할 수 있는 AI 프롬프트 수를 보여줍니다.

제한은 다음에 따라 달라질 수 있습니다.

- 일일 제한
- 주간 제한
- 구독 또는 권한 상태
- 추가 프롬프트 뱅크
- 이미 실행 중인 AI 요청 여부

프롬프트가 없으면 새 AI 요청은 차단됩니다. 요청이 이미 실행 중이면 기다리거나 중지한 뒤 다시 보낼 수 있습니다.

### AI 채팅을 쓰기 좋은 경우

AI 채팅은 사용자가 무엇을 해야 할지 알고 싶거나, Mixroom이 지원하는 작업을 실행시키고 싶거나, 믹스/편집 개념 설명이 필요할 때 사용합니다.

예시:

- "Make the vocal clearer."
- "Why does this sound muddy?"
- "Use track 4 as a reference and make the rest of the mix closer."
- "Split the selected clip at the playhead."
- "Create a filter sweep into the drop."
- "Write a simple bassline."
- "How do I export?"

AI 채팅은 사용자의 청취 판단을 대체하지 않습니다. 게인, EQ, 다이내믹스, 오토메이션, 마스터 버스 변경은 반드시 들어보고 확인해야 합니다.

## 22. AI 채팅 모드

### 정보 모드

질문과 설명에 사용합니다.

예시:

- "What does a compressor attack control do?"
- "Why does my vocal sound harsh?"
- "How do I export this project?"
- "Explain what changed in my mix."

정보성 프롬프트는 프로젝트를 편집하지 않습니다.

### 믹싱 모드

믹스 변경에 사용합니다.

예시:

- "Turn the vocals up a little."
- "Make the drums punchier."
- "Clean up the muddy low mids."
- "Add subtle reverb to the lead vocal."
- "Balance the whole song."
- "Put a limiter on the master."

믹싱 작업 대상:

- 하나의 Row
- 여러 Row
- 마스터 버스
- 전체 믹스

지원되는 믹스 작업 계열:

- gain
- pan
- balance
- EQ
- compressor
- limiter
- clipper
- reverb
- delay
- distortion
- de-esser
- reference-track matching

지원되는 EQ 스타일 표현:

- muddy
- boxy
- boomy
- harsh
- bright
- thin
- dull
- sibilant
- warmth
- presence
- air
- low cut
- high cut

### 레퍼런스 트랙 믹싱

레퍼런스 트랙 믹싱은 프로젝트 안의 기존 Row를 기준 사운드로 사용합니다. AI는 레퍼런스 Row와 대상 Row를 비교해 믹스를 그 방향으로 조정할 수 있습니다.

매칭 가능한 요소:

- 톤
- 라우드니스
- 스테레오 폭
- 글루/컴프레션 느낌
- 전체 믹스 느낌

예시:

- "Use track 6 as the reference and match the rest of the mix loosely."
- "Make my mix closer to the reference track, but do not change the reference."
- "Match the tone and width of the selected reference track."

AI는 레퍼런스 Row 자체는 편집하지 않습니다. 그 Row를 비교 대상으로 사용하고, 선택된 Row 또는 관련 Row를 조정합니다. 레퍼런스 Row가 불명확하면 Mixroom이 확인을 요청하거나 레퍼런스를 찾을 수 없다고 안내할 수 있습니다.

### DAW 어시스턴트 모드

에디터 작업에 사용합니다.

예시:

- "Show me where the export button is."
- "Split the selected clip at the playhead."
- "Move this clip one bar later."
- "Create a filter sweep into the drop."
- "Write a bassline for C-D-G-C."
- "Separate this clip into vocals and instrumental."
- "Set track 1 role to vocals."

## 24. AI 안전, 확인, 제한

AI 작업은 DAW가 지원하는 작업 시스템 안에서만 실행됩니다. 프로젝트를 임의로 마음대로 다시 쓰지는 않습니다.

일부 믹스 요청은 바로 적용될 수 있습니다. 다른 요청은 제안을 만들고 사용자가 "yes" 또는 "no"로 확인해야 적용될 수 있습니다.

대상이 모호하면 AI가 확인을 요청할 수 있습니다.

- "Trim the clip."
- "Automate the filter."
- "Move it right."

프롬프트 제출은 다음에 의해 제한될 수 있습니다.

- 일일 프롬프트 제한
- 주간 프롬프트 제한
- 추가 프롬프트 뱅크
- 이미 처리 중인 요청

Stop 버튼은 진행 중인 채팅 흐름을 중단할 수 있습니다.

- 이펙트 이름

- 대기 중인 믹스 제안
- 관련 샘플 라이브러리 요약

일반적인 클라우드 채팅 경로에서는 원본 오디오 파일, 렌더된 스템, 파형 버퍼, 전체 프로젝트 파일, 전체 플러그인 상태, 완전한 오토메이션 포인트 데이터가 전송되지 않도록 설계되어 있습니다.

## 26. AI 제한 사항

AI는 강력하지만 사용자의 판단을 대체하지 않습니다.

현재 제한:

- 구현된 액션 계열만 지원합니다.
- 대상이 불명확하면 확인을 요청할 수 있습니다.
- 한 번의 프롬프트로 전문적인 최종 믹스를 보장하지 않습니다.
- 빈 프로젝트에서 완성곡 전체를 만들어 주는 기능은 아닙니다.
- 일반 DAW 채팅 경로에서 새 보컬이나 악기를 완전히 생성하지 않습니다.
- 클라우드 채팅 경로에서 직접 오디오 이해를 위해 원본 오디오를 보내지 않습니다.
- 스템 분리, 플러그인, MIDI 변환, 내보내기는 로컬 엔진 지원에 따라 달라질 수 있습니다.

내보내기나 공유 전에는 AI 변경 사항을 확인하세요.

## 27. 실전 AI 프롬프트 예시

### 믹싱

- "Make the vocal clearer but not louder."
- "Reduce harshness on the guitar."
- "Tighten the low end."
- "Make the drums punchier."
- "Add a little air to the master."
- "Balance all active rows so the vocal stays in front."
- "Use the selected track as a reference and match the mix loosely."

### 편집

- "Split the selected clip at the playhead."
- "Move this clip one bar later."
- "Duplicate the selected clip."
- "Detect this loop's tempo and set the project BPM."
- "Reverse this audio clip."

### 오토메이션

- "Create a sidechain pump on the pad."
- "Add a filter sweep into the drop."
- "Fade the reverb up at the end of this phrase."
- "Clear automation on this lane."

### MIDI

- "Write a simple bassline for C-D-G-C."
- "Chop these MIDI notes into 16ths."
- "Humanize the selected MIDI notes."
- "Transpose the selected notes up an octave."

### 도움말

- "Show me where to add plugins."
- "How do I use the piano roll?"
- "Where is the export button?"
- "Explain what a de-esser does."
